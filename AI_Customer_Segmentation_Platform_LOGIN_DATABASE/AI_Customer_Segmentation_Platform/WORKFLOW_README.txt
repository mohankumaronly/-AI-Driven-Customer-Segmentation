AI CUSTOMER SEGMENTATION PLATFORM - STEP-BY-STEP WORKFLOW

1. Extract the complete ZIP file.
2. Double-click run_project.bat (or use the existing PowerShell instructions).
3. Open http://127.0.0.1:5000.
4. Upload a dataset: only the initial dataset analysis is shown.
5. Click Continue to AI Data Cleaning: only the cleaned dataset stage is shown.
6. Click Continue to AI Customer Segmentation: segmentation and business analytics are shown.
7. Click the Power BI button to show the Power BI dashboard stage.

Keep the terminal window open while using the website.
